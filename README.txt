Сайт предложения MetaFrame для SSD / VELOR Academy. Статический, без сборки.

Деплой:
- Vercel / Netlify: перетащить папку (или zip) в панель, либо `vercel --prod` из этой папки.
- Любой хостинг/nginx: загрузить содержимое в корень сайта.

Состав: index.html + папка img/. В index.html стоит noindex — страница не попадёт в поиск.
